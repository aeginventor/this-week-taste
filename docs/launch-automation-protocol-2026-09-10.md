## 수집 검토안 (2026-09-10 사용자 승인)

사용자가 목록 최대 5페이지·본문 최대 40개·순차 최소 1초 간격의 일회성 비공개 확보를 승인했다. 기존 자료를 재사용하며 정기 수집·공개 재배포·상업 이용 허가·배포는 포함하지 않는다. 아래 과거 개발 기록의 승인 대기는 당시 상태다.

- 소스: 신세계그룹 뉴스룸의 SCK COMPANY 공식 분류.
- 시작 경로: `https://www.shinsegaegroupnewsroom.com/family/sckcompany/`, 해당 분류의 페이지 링크와 그 목록에서 발견된 같은 호스트의 기사 URL만 따라간다. 내부 WordPress JSON은 사용하지 않는다.
- 기간: 게시일 2026-08-01~2026-09-08. 해당 기간 모든 분류 게시물을 대상으로 하고 제목에 ‘출시’가 있는 글만 고르지 않는다. 페이지 날짜 범위가 시작일을 지나갈 때까지 읽되 목록 최대 5페이지·기사 최대 40개에서 멈춘다. 초과는 불완전 수집으로 보고한다.
- 빈도: 이번 한 번의 고정 기간 자료 확보. 순차 요청·최소 1초 간격·기존 승인된 UA·robots 준수. 재현과 추출 재시도는 저장 사본을 사용한다. 예약·반복 네트워크 수집을 만들지 않는다.
- 비공개 보관: 기존 데이터 저장소의 `research/launch-automation-2026-09-10/`. HTML 원본, 목록, 확인시점·URL·지문, 문단 위치, 카탈로그 사본, 추출 입력/출력, AI 정답 후보, 평가 결과를 보관한다. 기존 raw/snapshots/weeks는 덮어쓰지 않는다.
- 공개 기록: 구현 코드·합성 테스트·측정 조건·집계·짧게 서술한 사례·공식 링크만 저장소에 남긴다. 기사 본문·이미지·교재 원문·비밀값을 공개하지 않는다.
- LLM: 최초 계획인 Claude CLI/Haiku는 실제 호출에서 조직의 구독 접근 차단으로 실패했다. 사용자는 이후 로컬 Qwen3 8B 설치·실험을 선택했다. Ollama 0.33.3, Qwen3:8b Q4_K_M, 127.0.0.1:11435, 클라우드 기능 비활성으로 실행한다. 본문 텍스트만 전달하고 정답·카탈로그·도구를 모델에게 주지 않는다. 모델 사용 승인은 아래 새 소스 자료 확보 승인과 구분한다.
- 조건: [뉴스룸 정책](https://www.shinsegaegroupnewsroom.com/policy/)은 저작자 표시·비영리·변경금지 및 개인 용도를 명시한다. robots 허용을 재사용 허가로 해석하지 않는다. 이번 개인 비공개 분석 범위를 사용자가 검토하며, 상업 서비스 이용 허가를 획득했다는 뜻은 아니다.
- 승인 근거: [AGENTS.md 7장](../AGENTS.md)은 ‘새 소스의 이용약관’을 실행 전 사람의 검토 대상으로 정한다. 기존 승인은 읽기 전용 조사·격리 연결이었으며 자동 자료 확보와 원문의 지속 보관은 구체 범위를 확인한다.

## 개발·평가 분리

기존 8월 27일 호지 라떼 발표와 같은 내용의 중복 URL은 전부 개발용이다. 이전 대화에서 본문을 읽은 9월 7일 라떼 행사·9월 3일 개인컵·9월 2일 선물 기사는 개발용으로 둔다. 나머지 기간 내 자료는 최종 평가용이다. 개발용과 본문이 같은 중복은 평가에 포함하지 않는다.
분할과 AI 정답 후보를 자동 추출 평가 실행 전에 지문으로 고정한다. 평가 결과를 본 뒤 프롬프트를 수정하면 새 버전의 개발 결과로 명시하며 같은 자료의 독립 평가라고 부르지 않는다.

정답 후보는 AI가 원문을 읽어 만든 것이며 독립적인 사람의 검수가 아니다. 식음료의 명시적 신규/복귀, 프로모션/무관 글, 여러 제품·날짜를 따로 기록한다. 종류나 시점이 불명확하면 불확실로 남긴다. 대표적으로 약속을 바꿀 모호성만 사용자에게 묻는다.

## 평가 단위

1. 목록에 나타난 기간 내 URL 수 → 중복 본문을 제외한 문서 수 → 본문 확보 성공 수를 나눈다. 분류에서 빠진 발표와 전체 시장 출시는 분모 밖이다.
2. 고정 평가 문서의 식음료 사건(제품 계열·종류·날짜)을 추출 정답 후보와 대조한다. 근거 없는 주장, 놓친 충분한 근거, 근거 부족을 구분한다.
3. 추출 주장의 정확성과 제품 연결의 정확성을 별도로 평가한다. 잘못 추출한 주장에 이름이 맞아도 성공으로 세지 않는다.
4. 계열 연결은 브랜드·이름·식음료 종류·판매 맥락·특징 설명을 함께 검사한다. 온도·크기·포장 변형은 본문이 뒷받침하지 않으면 개별 출시로 확장하지 않는다. 공개 제품 약속은 변경하지 않는다.
5. 규칙 기준선과 LLM을 같은 입력으로 비교한다. 규칙은 명시적 문장만 취하며 무조건 보류를 성공으로 계산하지 않는다.
6. 네트워크·추출·연결 실행 시간, LLM 호출 수·토큰, 검토할 항목 수를 기록한다. 로컬 실행의 외부 API 청구는 없지만 다운로드·메모리·기기 실행·전력은 별도 비용이다. 사용자의 실제 검토 시간과 전기 비용은 측정 전 추정하지 않는다.
7. 동일 저장 입력 재현, 문서 지문 변경, 추출 오류, 모호한 제품, 문서 속 실행 지시를 검증한다. 고정 LLM 출력의 코드 재현과 새 LLM 호출의 변동은 나눠 측정한다.

## 기존 수동 부분과 이번 변경

기존 실험은 AI가 기사 URL을 골랐고 본문을 읽어 제품·사건·날짜·맥락을 JSON에 직접 썼다. 코드가 한 일은 그 주장과 이름 후보 연결뿐이었다.
이번에는 고정 기간 발견·본문 파싱·주장 추출·연결·검토용 출력까지 실행한다. 평가 정답 후보와 모호성의 제품 판단은 사람이 검토할 수 있게 남긴다. 추출 실패는 ‘출시 아님’이 아니라 ‘이번 근거 없음’이며 기존 새 발견을 지우지 않는다.

운영 코드와 curate 프롬프트는 변경하지 않는다. ADR-0016의 전체 제품 카탈로그화 기각을 되살리는 작업도 아니다. 실험 코드·기록을 제거하면 되돌릴 수 있다.

## 개발 실행 상태 (2026-09-10)

설치와 저장된 개발 기사 1편의 로컬 자동 추출·연결·재현 검증은 완료했다. 기간별 발견·본문 수집과 실제 최종 평가 세트는 승인 대기로 미실행이다. 합성 반례 3건을 실제 발표 평가로 대체하지 않는다.
프롬프트를 보강해도 모델의 월 계산 오류가 남아, 사건·제품 관계는 LLM이 읽고 좁은 날짜 표현의 달력 계산은 코드가 맡도록 개발했다. 원시 모델 출력, 날짜 보정, 근거 문단이 없는 특징 제거 내역을 분리한다. 모델 단독 정확도와 이 처리 후 결과를 혼합하지 않는다.

상세 결과·재현·한계는 [작업 기록](../learning/sessions/2026-09-10-로컬모델-출시근거-자동화.md)에 연결한다. 추가 자료를 확보해 평가하기 전 운영 모델 채택이나 ADR의 유지할 설계 결정으로 승격하지 않는다.
