# 이번 주 신상 후보를 실제 콘텐츠와 대조했다

GS25 공식 공개 본문에서 **이번 주 출시 1개·예정 4개**를 발행안에 추가했다.
일반 쇼츠에서 확인한 와샤오롱은 지난주 CU 발행과 겹쳤다. 돈찐 원문은 접근하지 못했다.
공식 발표가 모든 후보의 필수 조건이라는 이전 추천은 [ADR-0020](adr/0020-new-products-and-upcoming.md)으로 변경됐다.
이 문서는 같은 날 앞선 [경로 비교](collection-route-review-2026-09-10.md)의 새 표본 조사이며 과거 실험을 다시 쓰지 않는다.

## 이번 비교의 범위

관측일은 2026-09-10 KST, 소개 주차는 W37(9월 7~13일)이다. 최근 콘텐츠는 9월 4~10일에 게시되었거나
열람 화면에서 최근 게시로 표시된 식품·편의점 자료를 골랐다. 영상 제목의 날짜를 실제 게시일·출시일로 대신하지 않았다.
GS25 본문 2개에서 6개, 공식 쇼츠 설명에서 1개, 디에디트 본문에서 식품 4개, 일반 쇼츠 재생 화면에서 1개,
총 12개 제품 후보를 대조했다. 전수 수집·무작위 표본이 아니며 정확도·시장 커버리지의 분모가 아니다.
과거 비교는 비공개 W33·W35·W36·W37 스냅샷 59개와 공개 W35·W36 발행을 사용했다.
정규화 이름 검색은 대조 출발점이다. 같은 계열 이름만으로 SKU를 합치지 않았다.

GS25 보도자료 목록 화면의 날짜와 상세 본문의 날짜가 달랐다. 상세 본문의 상품별 사건 날짜를 사용했다.
그 자료를 옮긴 뉴시스·다른 기사를 독립 증거 수로 더하지 않았다.
GS25 사진은 행사·여러 상품 사진이라 개별 상품에 대응을 확정하지 못해 카드에서 비웠다. 다른 사람 사진을 복제하지 않았다.

일반 쇼츠는 [@오늘은뭐먹지](https://www.youtube.com/@%EC%98%A4%EB%8A%98%EC%9D%80%EB%AD%90%EB%A8%B9%EC%A7%80/shorts)에서
9/9·9/3·9/2·8월 여러 날짜의 반복 신제품 소개 제목을 확인했다. 공식 브랜드 채널로 확인된 계정은 아니다.
대상 영상 설명은 열람 시 ‘8시간 전’으로 표시됐고, 상품 소개 화면 한 구간을 읽었다. 세 상품 전체·음성 전체를 분석했다고 주장하지 않는다.
제품 사진 소개 형식이며 독립 구매 후기인지 확인하지 못했다. 보도와 같은 홍보자료를 썼을 가능성이 있어 하나의 원자료 묶음으로 취급했다.

[맛상무의 9월 둘째 주 리뷰](https://www.youtube.com/watch?v=Gt_2SFdpSqc),
[냠그린의 9월 GS25 소개](https://www.youtube.com/watch?v=CiIcjbdAHUI),
[찌콩먹콩의 9월 1주차 소개](https://www.youtube.com/watch?v=YU-k2GNLxLA)는 이번 검색 화면에서 최근 제목·상품 설명만 확인했다.
영상 본문 분석이나 이번 표본의 신규 발견 건수에 포함하지 않았다. 오래된 2020년 영상으로 최근성을 대신하지 않았다.

## 돈찐은 무엇을 확인하지 못했나

대상 [돈찐 블로그](https://m.blog.naver.com/don_jjin)는 웹 읽기 오류와 브라우저의 사이트 보안 정책 차단으로 원문을 열지 못했다.
다른 주소·도구·피드·복사본으로 본문을 우회 확보하지 않았다. 작성자에게 연락하지 않았다.
검색에서는 오래된 외부 언급과 ‘26년도 비빔면 신제품 3종 리뷰’라는 제목 단서 등이 나왔지만 최근 주간 글 본문은 읽지 못했다.

| 요청된 분석 | 확인 상태 |
|---|---|
| 최근 주간 글의 브랜드·판매 채널 분포 | 미확인 |
| 출시 예정과 이미 출시된 제품의 표시 방식 | 미확인 |
| 출처 링크·이미지 출처·공식 계정·반복 자료 형식 | 미확인 |
| 작성자가 정보를 수집하는 실제 방법 | 미확인. 검색 제목으로 추정하지 않음 |

후보 발견 경로로서의 가치는 아직 미측정이다. 허용된 공개 본문을 읽을 수 있어야 제품명·판매처·날짜 표현·링크만 최소 기록하고
다른 자료·과거 관측과 대조할 수 있다. 설명문·사진의 복제와는 다르며 공개로 보인다는 것이 재사용 허가는 아니다.
[네이버 약관](https://policy.naver.com/rules/service.html)의 승인 없는 자동 수집 제한과
[블로그 검색 API 명세](https://developers.naver.com/docs/serviceapi/search/blog/blog.md)를 확인했다.
검색 API는 원문 전체 접근 권한이 아니고 키도 없다. 검색 결과 AI 입력·캐싱 조건은 앞선 비교에서 확인한
[개발자 공지](https://developers.naver.com/notice/article/33400)를 재사용한다. 이를 해결한 것처럼 자동 수집기에 연결하지 않았다.

## GS25 접근 경로와 이용 범위

[현재 공식 브랜드 페이지](https://www.gsretail.com/brand/gs25)에서 공식
[Instagram @gs25_official](https://www.instagram.com/gs25_official/)와
[YouTube @official_GS25](https://www.youtube.com/@official_GS25)를 확인했다.
YouTube 채널·최근 Shorts 목록과 위 설명은 읽었다. Instagram 최근 피드 본문은 이번에 확보하지 못했다.
공식 채널의 공동 게시 영상도 일반 계정의 독립 후기라고 세지 않는다.

이번 [robots.txt](https://www.gsretail.com/robots.txt)는 `/api/` 제한, Crawl-delay 10초, UTC 04:00~08:45 수집 창을 표시했다.
공개 보도자료 화면을 읽었으며 숨은 API를 호출하거나 앱 인증을 우회하지 않았다. 외부 개발자가 사용할 수 있는
현행 상품 API 문서는 확보하지 못했다. ‘API가 없다’는 결론은 아니다.
공개 본문 읽기와 최소 상품 사실·링크 검토만 했고, 본문·사진 재배포나 반복 수집 허가까지 확인한 것은 아니다.
GS25 서비스 범위는 유지하고 정기 수집은 별도 미도입으로 남긴다.

## 다음 시험: 운영 수집기를 늘리기 전에

1. **GS25 공개 안내 + 공식 Shorts 설명의 작은 주간 비교**: 다음 주에도 출시·예정 후보와 과거 목록 중복을 대조한다.
   이번에는 5개 추가가 있었으므로 우선순위가 높다. 두 주 연속 유용한 추가 정보가 있고 후보별 검토 시간·모호함을 기록할 수 있으면 계속한다.
   대부분 행사·기존 상품 재소개이거나 접근·반복 이용 조건이 미해결이면 자동 수집은 보류한다.
2. **일반 주간 소개 콘텐츠 → 다른 자료·과거 발행 대조**: 오늘은 뭐 먹지?와 디에디트처럼 출처가 다른 소수 자료를 같은 기간에 비교한다.
   이번은 5개 제품 후보에서 추가 0개였다. 독립된 신상품 후보가 남는지, 또는 후기·구매 맥락만 더하는지 측정한다.
   공식 발표가 없어도 구체적인 제품·시점·다른 관찰과의 일치가 충분하면 날짜 없이 포함할 수 있다. 전부 중복이면 참고 역할로 축소한다.
3. **돈찐은 접근 가능한 원문 표본을 확보한 뒤 비교**: 우회 없이 읽을 수 있는 범위가 확인될 때 1~2주 글의 제품 사실·링크만 대조한다.
   원문을 못 읽거나 자동 처리 조건을 해결하지 못하면 채택하지 않는다. 지금 ‘최고의 수집 경로’로 추천할 근거는 없다.

기존 카탈로그는 상품 정보·동일성 대조의 중심으로 유지한다. 푸드QR/HACCP 공개 API는 앞선 명세 조사를 재사용하며
바코드·규격 대조 역할이다. 이번 API 호출이나 새로운 카탈로그 수집기는 추가하지 않았다.
YouTube는 [공식 Data API](https://developers.google.com/youtube/v3/docs/search/list)를 통한 제목·설명·게시시각 조회 경로가 있지만,
키·[개발자 정책](https://developers.google.com/youtube/terms/developer-policies)의 보관·파생 이용 조건이 필요하다.
영상·음성·자막을 내려받지 않았다. Instagram 개인 피드·로그인 카페 수집도 자동화하지 않았다.

다음 정기 콘텐츠 시험을 승인받는다면 제안 범위는 GS25 공개 보도자료와 Shorts 설명의 새 링크를 주 1회 확인하고,
필요한 상품 사실·링크·확인 시각만 비공개에 보관하는 것이다. 본문·영상·사진·개인정보를 저장하지 않는다.
현재 승인된 것은 이번 읽기 조사와 발행 준비이며 이 반복 수집을 이미 켜 둔 것은 아니다.
