# 로컬 모델 재실행 전 점검

2026-09-10, macOS. **배포 지문·설치 파일·모델 지문을 대조한 뒤 최소 동작만 재확인했다.**
보안 인증이나 기사 추출 품질 검증으로 해석하지 않는다. 기사는 다시 추론하지 않았다.

| 확인 | 결과와 한계 |
|---|---|
| 설치 출처 | Ollama GitHub `v0.33.3`, 9월 2일 공개. 공식 릴리스 API의 macOS tgz digest와 로컬 159,236,337바이트 파일이 일치했다. |
| 압축파일 SHA-256 | `342db03df80bb9db84ff64246031bd5f70c09b59ff52fa5cc9aaae3476cc4a9d` |
| 설치 내용 | 실행 파일·라이브러리 등 일반 파일 45개의 바이트가 압축파일과 일치했다. `._mlx.metallib` 두 메타데이터 사이드카는 설치 경로에 없었다. |
| 코드 서명 | 샌드박스 안 `codesign --verify --strict`는 실패했다. 같은 파일을 샌드박스 밖에서 일반·strict 검사하니 둘 다 valid on disk와 지정 요구사항 충족으로 끝났다. 바이너리를 바꾸거나 서명을 우회하지 않았다. |
| 모델 출처·형식 | Ollama registry의 `qwen3:8b`, Q4_K_M. manifest SHA-256 `500a1f067a9f782620b40bee6f7b0c89e17ae61f686b92c24933e4ca4b2b8b41`; config 포함 5개 blob의 크기·digest 일치. |
| 실행 설정 | `127.0.0.1:11435`, cloud 비활성, 동시 실행 1, 모델 경로 비공개, 도구 없음. 시험 프로세스에는 비밀값 환경변수를 넘기지 않았다. |
| 최소 재실행 | API 버전 0.33.3·등록 모델 digest 확인, 합성 입력에 `{"ok":true}` 응답, 약 2.22초. 모델 다운로드·기사 수집·날짜 규칙 개선 없음. |
| 종료 확인 | 이 작업이 띄운 서버를 종료했다. 종료 뒤 11435 리스너가 없었다. 자동 시작 서비스는 등록하지 않았다. |

출처: [공식 배포](https://github.com/ollama/ollama/releases/tag/v0.33.3), [Ollama 설정 문서](https://docs.ollama.com/faq), [Qwen 공식 모델 카드](https://huggingface.co/Qwen/Qwen3-8B).
Qwen 원본의 Apache 2.0 라이선스는 Ollama 양자화 파일의 모든 보안 속성을 증명하지 않는다.

## 알려진 취약점과 남은 범위

- [CVE-2026-7482](https://github.com/advisories/GHSA-x8qc-fggm-mpqg): GGUF 로더의 메모리 범위 밖 읽기. 공지의 영향 범위는 0.17.1 미만이고 0.33.3은 그 범위 밖이다. 이것으로 모든 취약점이 해결됐다고 결론 내리지 않는다.
- [CVE-2026-15685 / ZDI-26-403](https://www.zerodayinitiative.com/advisories/ZDI-26-403/): 모델 다운로드 처리의 인증 없는 서비스 거부. 공개 공지에는 수정 버전이 없다. 0.33.3에서 해결됐다고 확인할 수 없다. 이번 시험은 고정된 로컬 모델만 사용했고 pull/create/push 경로를 호출하지 않았다.
- [공개 이슈 #16654](https://github.com/ollama/ollama/issues/16654)의 여러 공격 주장은 공식 수정 범위가 확인된 보안 권고와 구분했다. 출처 불명의 공격 코드나 취약점 시험은 실행하지 않았다.

loopback·cloud 비활성은 위험을 줄이는 설정이지 완전한 격리가 아니다. 로컬 다른 프로세스는 API에 접근할 수 있고, 과거 로그의 허용 Origin에는 localhost와 앱 스킴이 들어 있다. 향후 지속 실행이나 외부 공개를 하려면 인증·접근 제한과 해당 버전의 수정 여부를 다시 검토해야 한다.

원문 서버 로그·실행 파일·모델은 Git에 추가하지 않았다. 비공개 데이터 저장소에는 점검 결과 메타데이터만 보관한다.
기존 [기사 평가 재현](../research/launch-study-20260910/README.md)은 저장 응답으로 충분하며 모델 실행을 요구하지 않는다.
