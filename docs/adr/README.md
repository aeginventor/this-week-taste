# 설계 결정 기록 (ADR)

되돌리기 어려운 결정과 그 근거를 남긴다. 코드를 보면 *무엇을* 했는지는 알 수 있지만
*왜 다른 선택지를 버렸는지*는 알 수 없다. 그걸 여기 적는다.

## 형식

```
# ADR-NNNN 제목

상태     제안 | 채택 | 폐기 | ADR-NNNN으로 대체됨
날짜     YYYY-MM-DD

## 맥락      무슨 상황이었고 무엇이 걸렸나
## 결정      무엇을 정했나
## 결과      그래서 무엇을 얻고 무엇을 감수하나
## 버린 대안  왜 안 골랐나
```

## 무엇을 적고 무엇을 안 적나

**적는다** — 되돌리는 비용이 시간이 갈수록 커지는 결정. 저장 방식, 식별자 체계,
계층 경계, 기술 스택. 그리고 **번복에는 계기를 반드시 함께 적는다.**
계기가 실측이거나 요구사항 변경이 아니면, 그건 기록할 결정이 아니라
다시 생각해야 할 결정이다.

**안 적는다** — 라이브러리 선택 같은 되돌리기 쉬운 것, 코드에 주석으로
충분한 것, 아직 실제로 결정하지 않은 것.

## 기록을 고치지 않는다

결정이 바뀌면 기존 기록의 **상태만** `대체됨`으로 바꾸고 새 기록을 추가한다.
내용은 그대로 둔다. 그때 무엇을 알고 있었는지가 기록의 값이다.
