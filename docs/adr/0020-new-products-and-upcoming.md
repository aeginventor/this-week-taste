# ADR-0020 신상과 출시 예정 상품을 폭넓게 소개한다

상태  채택 — 사용자의 명시적 제품 방향 변경
날짜  2026-09-10

## 무엇이 문제였나

카탈로그의 새 등록과 실제 출시가 다르다는 발견은 유효했다. 그러나 화면을 “발견 기록”으로
바꾸고 모든 상품에 “출시 미확인”을 붙이는 선택은 신상을 유용하게 소개하려는 목적에서 멀어졌다.
GS25 웹 카탈로그의 중단도 브랜드 전체의 정보 제공 불가를 뜻하지 않는다.

## 사용자가 정한 방향

- 그 주에 나온 상품과 앞으로 나올 상품을 폭넓게 소개한다. 초단위 속도·완벽한 정확도보다 누락을 줄인다.
- “신상” 화면을 유지한다. 내부 출처·날짜·불확실성·검토 상태를 상품마다 노출하지 않는다.
- 공식 발표가 없는 후보도 구체적인 다른 근거로 검토한다. 근거·출시일을 지어내지 않는다.
- GS25는 서비스 대상에 남긴다. 차단된 경로를 우회하지 않고 다른 경로를 찾는다.
- 원문·개인정보·모델은 공개 저장소에 넣지 않는다. 작성자의 설명문·사진 복제와 상품 사실·링크 활용을 구분한다.

## AI가 제안하고 구현할 최소 구조

카탈로그 경로는 그대로 사용한다. 동일성·과거 관측·입력 검증은 실제 반례를 막으므로 유지한다.
별도로 비공개 `candidates/<week>.json`에 콘텐츠에서 발견한 후보, 근거 링크와 확인 범위,
날짜 주장, 과거 관측 대조, 포함·보류 이유를 보관한다. 검토를 통과한 상품 필드만 기존 주간 발행물에 합친다.
콘텐츠 목록에는 snapshot 차집합이나 removed를 적용하지 않는다. 범용 기사 추출기·모델은 추가하지 않는다.

포함 기준은 점수 합산이나 “공식 링크 두 개” 같은 기계적 문턱으로 만들지 않는다.

| 판단 | 실용적인 기준 |
|---|---|
| 포함 | 제품·브랜드·판매처가 구체적이고 최근 신상/리뉴얼/예정임을 설명하는 근거가 있다. 제품 정보와 과거 관측을 대조했으며 중대한 모순이 없다. 공식 단일 자료나 구체적인 비공식 자료도 근거가 될 수 있다. |
| 날짜 없이 포함 | 이번 주 카탈로그 추가 등 최근 소개할 이유가 있지만 출시일이 명시되지 않았다. 날짜를 비워 두고 근거와 남은 불확실성은 내부 기록에 남긴다. |
| 출시 예정 | 해당 상품이 앞으로 나온다는 구체적인 자료가 있다. 정확한 날짜가 있으면 표시하고, 예정이라는 주장만 있으면 날짜는 생략한다. |
| 보류 | 상품 대응·맛/규격이 모호함, 오래된 제품과 강하게 겹침, 시점 주장 충돌, 검색 요약만으로 중요한 주장을 확인하지 못함 등 해결할 문제가 있다. 공식 발표 부재 자체는 보류 사유가 아니다. |

같은 보도자료를 옮긴 기사·정리 글은 하나의 근거 묶음으로 센다. 독립 구매·포장 관찰은 별도 정보가
될 수 있지만 그것만으로 최초 출시일을 확정하지 않는다. 게시일은 게시일로 보관한다.
확인 가능한 출시일이 지난주라면 이번 주 출시로 바꾸지 않고 해당 주차나 보류 기록에 남긴다.
미래 상품의 소개 주차와 예정일은 서로 다른 값이다. 보관된 주차 화면의 예정 표시는 작성 당시 안내다.

화면은 주차 제목 “신상”, 공통 채널·브랜드·검색 필터 아래 “이번 주 신상”과 “출시 예정” 두 묶음을 사용한다.
예정 후보가 없으면 빈 묶음을 만들지 않는다. 상품에는 필요한 정보와 원문 링크를 표시한다.
새로운 검증 상태나 실패 설명을 소비자 카드에 추가하지 않는다.

## 유지하는 경계와 검증

ADR-0018의 주키 우선·모호한 매칭 보류·재등장 대조·공개 ID 보존과 ADR-0019의 입력 검증을 유지한다.
새 콘텐츠 입력도 잘못된 타입·중복 ID·날짜와 판단 불일치로 조용한 오발행이 나지 않도록 검사한다.
과거 발행 파일과 연구 동결본은 다시 쓰지 않는다. 과거 실패를 현재 코드의 성과로 바꾸지 않는다.
정기 콘텐츠 수집은 경로·빈도·보관 범위를 확인하기 전까지 자동화 완료로 간주하지 않는다.
