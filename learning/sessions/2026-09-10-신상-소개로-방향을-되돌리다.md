# 신상 소개로 방향을 되돌리다

## 사용자 결정

정확성 검증이 서비스 목적을 대체해서는 안 된다. 이번 주 신상과 출시 예정 상품을 폭넓게 소개하며,
화면의 “발견 기록”·상품마다 붙는 “출시 미확인”은 사용하지 않기로 명시적으로 변경했다.
공식 발표는 유용한 근거지만 모든 포함의 필수 조건은 아니다. GS25는 카탈로그 경로 중단과 별개로 대상에 남긴다.
원격 main 반영·배포는 최종 변경과 미리보기를 보고 판단한다. 옛 이력 재구성과 원격 브랜치 삭제는 하지 않는다.

## AI가 수행한 변경

ADR-0018의 과거 결정·반례는 보존하고 ADR-0020으로 현재 소개 정책을 추가했다.
상품 중복 판별과 발행 입력 검증은 유지한다. 화면은 공통 필터 아래 신상과 출시 예정 두 묶음으로 구성하고,
근거가 있는 날짜·출처 이름을 표시할 수 있게 했다. 과거 주간 JSON을 고치지 않았다.
GS25의 targets 기록은 브랜드 서비스 범위와 기존 카탈로그 접근 상태를 구분한다.

이 선택은 정확성을 포기하는 뜻이 아니다. “언제 출시됐다고 단정할 수 있는가”와
“지금 독자에게 소개할 가치가 있는가”를 분리한 것이다. 내부 검증 정보는 판단·복구에 쓰고 UI는 상품 탐색에 집중한다.

## 시작 상태 확인

2026-09-10 14:48 KST, 2026-W37(9월 7~13일). 두 원격을 갱신했고 작업 브랜치는
코드 `281a522`, 데이터 `ec784bd`였다. 원격 PR은 없고 두 작업 트리는 깨끗했다.
원격 main 데이터까지 포함된 W37 성공 스냅샷은 14개, 로컬 소스 3개는 파일 없음,
홈플러스는 W35 이월이었다. 성공본을 덮지 않고 네 소스만 순차 수집하기 시작했다.

## 접근 한계

돈찐 원문은 웹 읽기에서 오류가 났고, 브라우저는 사이트 보안 정책으로 접근을 차단했다.
우회하지 않았다. 공개 검색의 제목·링크 단서는 원문 분석과 구분하며 작성자의 수집 방식은 확정하지 않는다.
기존 연구의 과거 사례를 이번 주에 새로 발견한 성과로 세지 않는다.

## 첫 변경 검증

화면·규칙 변경 후 기본 테스트 638개 통과·3개 skip, 웹 타입 검사 통과, 스킬 형식 검사 통과를 확인했다.
이번 주 발행물과 실제 화면 미리보기는 다음 단계에서 확인하며 이 검사만으로 배포 성공을 주장하지 않는다.

## 콘텐츠 후보 연결 검증

별도 비공개 후보 파일에서 포함·보류를 읽고 상품 사실만 병합하는 작은 경로를 추가했다.
공식 발표가 아닌 구체적인 후기에도 날짜 없이 포함할 수 있다. 검색 요약만 읽은 출처, 잘못된 날짜·타입,
중복 ID는 거부한다. 명시적 카탈로그 연결은 기존 이름·ID를 유지하고, 이전 주 공개 이력의 first_seen도 보존한다.
전체 테스트 651개 통과·3개 skip를 확인했다. 이는 입력 계약 검사이며 후보 내용의 진실성에 대한 자동 판정이 아니다.

## 수집 자동화의 실제 결과를 확인한다

AI가 Actions에 읽기 전용 상태 검사를 추가했다. 이월 파일이나 다른 주차의 관측이 있다는 이유로
성공으로 오인하지 않게 실행 요약과 종료 코드에 반영한다. 실행이 아예 없는 문제는 이 검사로 해결되지 않으므로
별도 후속 확인을 사용한다. 652개 테스트 통과·3개 skip, 실제 W37 검사에서는 17개 성공·홈플러스 1개 이월을 확인했다.
로컬 전용 3개·LLM 편집·발행을 자동화했다고 주장하지 않는다. 변경된 schedule은 main 반영 전에는 적용되지 않는다.

교재 개념으로는 수집처별 실패 격리와 관측 가능성이 실제로 쓰였다. 프로세스 종료만 보는 대신 소스별 산출물의
주차와 상태를 확인한다. 새 추상화나 분산 시스템을 구축한 성과로 확대하지 않는다.

## 실제 발행 준비에서 드러난 실패

17개 수집처의 부분 파일 생성은 끝났지만 LLM 편집 121건은 모두 원본 폴백이었다.
로그인 상태 확인만으로 성공을 가정한 것이 잘못이었다. 작은 실제 호출에서 조직의 구독 접근 차단(403)을 확인했다.
다른 유료 모델·Ollama는 켜지 않았다. CU의 신선 과일 5개는 저장된 상세 설명과 과일 태그를 읽고
AI가 범위 밖으로 판단해 별도 제외 검토에 남겼다. 상품 ID·이름·소스·URL이 모두 맞을 때만 제외하도록 검증한다.

쇼츠의 와샤오롱 후보는 과거 관측 대조 결과를 적용하기 전에 잠시 로컬 발행안에 들어갔다.
실제 결과에는 W36 CU 공개 ID가 있었으므로 즉시 보류하고 다시 병합했다. 중간안은 커밋·푸시·배포하지 않았다.
독립적인 읽기와 그 결과를 사용하는 입력 작성은 순서대로 해야 한다는 실패 기록이다.

## 실제 화면에서 고친 부분

GS25처럼 개별 사진을 확인하지 못한 카드는 빈 정사각형이 상품명보다 먼저 보였다. 사진 없는 카드는
텍스트부터 표시하게 바꿨다. 긴 신상 목록 아래 예정 상품으로 바로 이동하는 링크를 추가했다.
하단의 ‘모든 정보가 브랜드 공식 사이트에서 왔다’는 문구도 각 항목의 실제 출처를 안내하도록 고쳤다.
이는 AI의 화면 구현 판단이며 사진을 만들어 채우거나 소비자 화면에 검토 상태를 붙이지 않았다.

## 이번 주 결과와 검증

W37 기존 14개 성공 관측은 재사용했다. 컴포즈 205개·맘스터치 66개·파리바게뜨 522개를 새로 수집했다.
홈플러스는 재시도에도 카테고리 감소 이상으로 W35 이월 상태다. 이전 W37 성공 부분 파일도 없어 이번 발행에서는 제외했다.
로컬 실행에는 Issue 생성 인증 환경이 없어 새 Issue를 만들지 못했고 실패 로그를 남겼다.

최종 발행안은 121개다. 카탈로그 후보 121개에서 신선 과일 5개를 제외하고 GS25 출시 1개·예정 4개를 더했다.
화면은 신상 소개 117개·출시 예정 4개다. 카탈로그 항목의 정확한 출시일을 모두 검증했다는 뜻은 아니다.
콘텐츠 후보 12개 중 5개 포함·7개 보류다. 돈찐은 원문을 못 읽어 이 분모에 넣지 않았다.
[후속 조사](../../docs/content-route-check-2026-09-10.md)에 읽은 범위·동일 홍보 묶음·과거 발행 중복을 기록했다.

최종 코드 회귀 검사 653개 통과·3개 skip, 정적 웹 빌드 통과. 이미지 6개 소스의 표본 49개가 열렸다.
GS25 5개와 오리온 2개는 이미지가 없으므로 이미지 검증 성공으로 세지 않았다.
최초 저장한 성공 스냅샷·원본 251개와 과거 공개 W35·W36 JSON 및 리포트는 바이트가 그대로다.
규칙 변경 뒤 현재 코드의 입력 지문으로 17개 소스를 다시 처리할 때는 저장 상세를 실제 파서에 공급해 네트워크 요청을 하지 않았다.
줄바꿈 변환을 피하도록 원문 바이트를 UTF-8로 읽었고 보강 내용 일치와 발행·리포트 generation_id 일치를 확인했다.
기존 CLI 실패 뒤 재처리는 off 모드였으므로 소개문은 카탈로그 116개 모두 비어 있고 GS25 4개에만 있다.
원본 분류가 그대로 보여 영문·혼합 분류도 남는다. 이를 편집 완료나 서비스 품질 개선 수치로 포장하지 않는다.

AI가 사용자의 명시적 요청에 따라 월·화 KST 21:30 실제 실행 후속 확인을 설정했다(automation-2).
첫 예정일은 9/14이며 기계·앱·인증이 사용 가능해야 한다. 다음 주 성공은 아직 확인하지 않았다.
main 반영과 배포는 아직 하지 않았고, 새 정기 콘텐츠 수집도 켜지 않았다. Ollama/Qwen은 필요하지 않아 실행하지 않았다.
