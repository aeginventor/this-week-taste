# 신상 소개로 방향을 되돌리다

## 사용자 결정

정확성 검증이 서비스 목적을 대체해서는 안 된다. 이번 주 신상과 출시 예정 상품을 폭넓게 소개하며,
화면의 “발견 기록”·상품마다 붙는 “출시 미확인”은 사용하지 않기로 명시적으로 변경했다.
공식 발표는 유용한 근거지만 모든 포함의 필수 조건은 아니다. GS25는 카탈로그 경로 중단과 별개로 대상에 남긴다.
원격 main 반영·배포는 최종 변경과 미리보기를 보고 판단한다. 옛 이력 재구성과 원격 브랜치 삭제는 하지 않는다.

## AI가 수행한 변경

ADR-0018의 과거 결정·반례는 보존하고 ADR-0020으로 현재 소개 정책을 추가했다.
상품 중복 판별과 발행 입력 검증은 유지한다. 화면은 공통 필터 아래 신상과 출시 예정 두 묶음으로 구성하고,
근거가 있는 날짜·출처 이름을 표시할 수 있게 했다. 과거 주간 JSON을 고치지 않았다.
GS25의 targets 기록은 브랜드 서비스 범위와 기존 카탈로그 접근 상태를 구분한다.

이 선택은 정확성을 포기하는 뜻이 아니다. “언제 출시됐다고 단정할 수 있는가”와
“지금 독자에게 소개할 가치가 있는가”를 분리한 것이다. 내부 검증 정보는 판단·복구에 쓰고 UI는 상품 탐색에 집중한다.

## 접근 한계

돈찐 원문은 웹 읽기에서 오류가 났고, 브라우저는 사이트 보안 정책으로 접근을 차단했다.
우회하지 않았다. 공개 검색의 제목·링크 단서는 원문 분석과 구분하며 작성자의 수집 방식은 확정하지 않는다.
기존 연구의 과거 사례를 이번 주에 새로 발견한 성과로 세지 않는다.

## 첫 변경 검증

화면·규칙 변경 후 기본 테스트 638개 통과·3개 skip, 웹 타입 검사 통과, 스킬 형식 검사 통과를 확인했다.
이번 주 발행물과 실제 화면 미리보기는 다음 단계에서 확인하며 이 검사만으로 배포 성공을 주장하지 않는다.
