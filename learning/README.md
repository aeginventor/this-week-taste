# 학습 기록

이 프로젝트를 만들면서 배운 것을 쌓는 곳이다. 코드가 "무엇을 하는가"를 말한다면
여기는 "왜 그렇게 정했고 무엇을 몰랐다가 알게 됐는가"를 말한다.

```
til/         개념 단위. 한 파일에 한 개념. 나중에 설명할 수 있을 만큼 적는다
sessions/    작업 단위. 그날 무엇을 결정했고 대안은 무엇이었나
raw/         대화 원문 보관. 커밋하지 않는다 (.gitignore)
```

## 쓰는 기준

**til/** 은 "이 개념을 처음 보는 사람에게 설명한다"는 가정으로 쓴다.
정의만 적으면 나중에 읽어도 아무것도 안 남는다. **이 프로젝트의 어디에서
실제로 걸렸는지**를 같이 적는다. 그 구체적인 사례가 개념을 붙잡아준다.

**sessions/** 는 결정 로그다. 무엇을 했는지가 아니라 **무엇을 고민했고 무엇을 버렸는지**를
적는다. 채택한 안만 적으면 나중에 "왜 저걸 안 했지?"를 다시 처음부터 고민하게 된다.

## 왜 나눴나

til은 시간이 지나도 유효하고 계속 보충된다. sessions는 그날의 기록이라 나중에 고치지 않는다.
수명이 다른 글을 한 폴더에 두면 어느 쪽도 관리가 안 된다.
