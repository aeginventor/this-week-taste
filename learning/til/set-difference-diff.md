# 차집합은 목록의 변화를 말한다

2026-09-09 개정. 이전의 ‘차집합으로 신상품 정의하기’ 설명은 [ADR-0018](../../docs/adr/0018-discovery-and-launch.md)로 수정됐다.

집합 A에서 B에 있는 원소를 빼는 연산이 차집합이다. 이번 목록을 A, 이전 목록을 B라고 하면
A−B는 이번 목록에만 있는 항목이다. 여기까지는 계산의 뜻이다.
이것을 실제 신제품이라고 부르려면 이전 목록이 제품의 출시 이력을 충분히 대표한다는
추가 근거가 필요하다. 온라인 입점, 재입고, 시즌 복귀, 누락 복구도 A−B에 들어갈 수 있다.

## 원소를 무엇으로 정하는가

CU W36에는 이전 주에도 있던 제품과 이름·바코드·가격이 같지만 등록 번호가 다른 항목이 있었다.
카탈로그 항목과 물리적 제품은 같은 단위가 아니다. 바코드 하나가 여러 등록을 가리킬 수 있다.

```text
원본 ID 동일 → 같은 카탈로그 항목을 먼저 연결
남은 항목의 보조 키 → 양쪽에서 한 후보일 때 연결
여러 대응 후보 → 보류
연결되지 않은 항목 → 목록 등장 후보
과거 관측 대조 → 새 발견 후보 / 재등장·중복 후보
공식 출시 근거 → 별도의 출시 판단
```

한 항목씩 먼저 매칭하면 입력 순서가 결론에 영향을 줄 수 있다. 우선순위가 높은 연결을
목록 전체에서 먼저 확정해야 한다. 같은 자료의 배열 순서만 바꾸는 테스트는 정답 총수가
같아도 선택된 대상이 바뀌는 오류를 찾아낸다.

## 신호와 정답을 구분한다

NEW 라벨과의 일치, 다음 주 목록 이탈, 등록 번호 증가 여부는 조사할 신호다.
어느 신호도 단독으로 실제 출시의 정답이 되지 않는다. 신호와 많이 겹친다는 이유로
출시 정확도가 높다고 계산하면, 처음 의심한 라벨을 다시 정답으로 삼게 된다.

통계 수업과 연결되는 지점은 평가할 대상을 먼저 정의하고, 측정한 값이 그 대상을
대표하는지 따지는 일이다. Python에서는 집합·딕셔너리가 구현 수단이지만,
알고리즘이 올바르게 계산한다는 것과 제품에 관한 주장이 맞다는 것은 별도로 검증한다.
